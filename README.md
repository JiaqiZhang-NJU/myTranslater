# myTranslater

基于网页结构的轻量双语翻译扩展，支持桌面版 Chrome / Edge。打开普通网页后，点击贴在页面右侧的「译」圆角按钮开始翻译，再点一次恢复原文。按钮可沿右侧上下拖动，按网站记住高度；移动超过 6px 后松手不会切换翻译。旁边的状态与操作在鼠标悬停、键盘聚焦或出现提示时显示。视频、直播或网页进入全屏时自动隐藏，退出后恢复，不会中断翻译。

当前版本为 **v0.5.0**，安装包通过官网下载页与 GitHub Releases 分发。

项目地址：[JiaqiZhang-NJU/myTranslater](https://github.com/JiaqiZhang-NJU/myTranslater)。官网与安装包下载页：<https://translate.jqzhang.top/>。

## 功能

- **两种翻译方式**：在设置页选择 DeepSeek API 或本机 Ollama 模型。
- **结构上下文**：按页面标题、章节、文本角色及邻近内容组织请求。导航短词带导航语境；简单表格的单元格带关联表头或行标题。多个相关文本合并请求，不另发一次 AI 摘要请求。
- **双语网页**：标题、段落、列表、普通导航（原生 `nav`、面包屑、分页、标签页、菜单和自定义导航容器）、按钮、`label` / `summary` / `caption` 标签，以及有明确表头的简单表格。译文保留可识别的链接与强调标记，数字徽标（如 `Matches (34)` 里的 `(34)`）保持原样，源网页文本和原有点击事件不被替换。
- **划词翻译**：选中任意可见文字后，用浏览器右键菜单选择「用 myTranslater 翻译所选文字」，结果在页面内的小面板显示，可复制。此入口不要求先开启整页翻译，也不会把译文插回页面。
- **动态网页**：开启后监听页面新增或改动，合并频繁变化，重新翻译受影响的区域，并丢弃旧请求返回的过时结果；切换页面 URL 后结束旧会话。
- **开放式 Shadow DOM**：递归扫描组件内部与嵌套根，按实际显示的插槽内容提取；跟进加载更多、展开回复、文字变化、插槽切换和延迟创建的开放根。隐藏区域、编辑框及 `translate="no"` 的排除规则跨越宿主与插槽。
- **布局保护**：正文与评论在空间允许时上下双语；导航与按钮使用紧凑译文。插入会检查裁剪、溢出、原文换行和邻近控件；空间不足时保留页面布局，通过原控件悬停或聚焦弹出译文，状态面板的「查看受限译文」提供统一入口。浮层可选中文字、按 Escape 或点击关闭；浮层显示也算完成，窗口缩放和菜单开关只重新检查显示方式。
- **当前页缓存**：恢复原文会取消未完成请求并保留成功译文；再次开启先复用，命中不请求模型、不增加用量。缓存按原文、实际上下文、行内标记和模型身份区分，DOM 重建会对应新节点。预算或按钮位置变化不使缓存失效；刷新、关闭或切换页面会清除。右键的「重新翻译当前页（重新消耗用量）」清空本页整页与划词缓存后重新请求。
- **按钮位置**：按网站 origin 保存可移动范围内的高度比例，最多保留最近使用的 200 个网站；右键可「重置按钮位置」。只有拖动完成或重置才写入位置，窗口缩放时按钮与面板保持在视口内。
- **当前页隐藏**：右键悬浮球选择「在当前页面隐藏悬浮球」会停止当前翻译并恢复原文；点工具栏扩展图标可在同一页恢复，刷新或切换页面后悬浮球也会重新出现。
- **全屏自动隐藏**：支持浏览器原生全屏，以及视频/直播播放器通过 CSS 铺满视口的「网页全屏」，包括播放器 iframe 铺满网页的情况。普通内嵌视频与未铺满视口的宽屏/影院模式仍显示按钮。网页全屏依据布局识别，特殊网站的自定义播放器可能需要适配；手动隐藏的按钮不会因退出全屏而重新出现。
- **页面预算**：设置页分别配置 DeepSeek、Ollama 的开关和正整数 token 上限，默认均开启、30,000 token。整页与划词共用当前方式的本页额度，状态显示后台累计用量与在途预留量；预算控制请求量，不代表账单金额。关闭限制仍累计用量。

## 支持的识别范围与边界

- 原生语义结构优先于普通容器：`nav`、`[role="navigation"]`、`[role="tablist"]`、`[role="menu"]`、`footer` 里的链接和标签会被识别。
- 普通 `div` / `ul` 导航依据结构判断：多个重复的同级链接、短标签、链接之外几乎没有文字。正文链接、图片卡片和「阅读更多」不会被当作导航。
- 一个文字节点只有一个归属：父项直接文字、子段落、嵌套列表和按钮各自成块，不重复请求。
- 明确排除脚本、样式、代码、输入值、隐藏内容、`translate="no"` 和扩展自身节点；整个可编辑区域（`contenteditable`）按一块跳过，其中的 `contenteditable="false"` 子区同样跳过。不在编辑器内的 `contenteditable="false"` 元素属于普通内容。
- 纯数字与符号不单独请求：页码、评分、徽标不会发给模型。
- 暂不支持：closed Shadow DOM、iframe 内容、Canvas 图片文字、PDF、字幕、虚拟化表格、合并表头与多级表头。播放器 iframe 的网页全屏识别仍支持，但不读取其文字。

## 下载与安装

1. 在官网 <https://translate.jqzhang.top/> 或 [Releases](https://github.com/JiaqiZhang-NJU/myTranslater/releases/latest) 下载最新的 `myTranslater-vX.Y.Z-chrome-edge.zip`，解压到一个固定文件夹。两处是同一个安装包。
2. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择**直接包含 `manifest.json`** 的解压文件夹。ZIP 本身和 GitHub 自动生成的 Source code 压缩包不能直接作为此步骤的安装目录。
4. 打开扩展设置页，选择 DeepSeek API 或 Ollama 本地模型并保存；刷新已经打开的普通网页，然后点击右侧「译」。

这是通过开发者模式加载的独立扩展，尚未通过浏览器扩展商店分发。升级时下载新版 ZIP、解压到原文件夹，再在扩展管理页点击「重新加载」。

## 从源码构建

需要 Node.js 22 或更新版本。

```powershell
npm ci
npm run typecheck
npm test
npm run build
```

可选的浏览器回归检查会启动本机 Chromium 内核浏览器，用固定样例验证结构覆盖、预算、缓存、动态更新、开放组件、插槽、防遮挡浮层、按钮拖动、全屏和划词面板。通过环境变量 `MT_BROWSER` 指定浏览器路径；找不到浏览器时脚本会打印 `SKIP` 并正常退出。单元测试中的真实 Ollama 集成默认为跳过，可设置 `OLLAMA_INTEGRATION=1` 和 `OLLAMA_MODEL` 启用。

```powershell
npm run build
npm run test:browser
```

`npm run test:install` 会把构建产物当作真实扩展加载，检查 service worker、`contextMenus` 权限、内容脚本注入、后台往返，以及设置页预算保存与重载。设置 `MT_LIVE=1` 可追加 MDN、Bilibili、YouTube 真实网页检查；使用本机固定响应服务验证提取和显示，不评估翻译质量，截图与结构记录写入本机 `docs/acceptance-v0.5.0/`。真实站点受网络、登录状态和动态内容影响，记录会明确区分页面未加载、内容未出现和实际验证结果。固定样例通过不能代替此检查。

普通安装版 Chrome 137 起会忽略命令行 `--load-extension`，脚本会尝试测试用 Chromium 并打印实际浏览器。在真实 Chrome/Edge 中手动加载与原生右键菜单点击仍需人工确认。

构建完成后，可以按上述步骤加载本项目的 `dist` 目录。更新代码后重新构建、在扩展管理页点击「重新加载」，然后刷新目标网页。

打开扩展设置页，选择一种方式并保存：

- **DeepSeek API**：填写 API Key。默认只保留在当前浏览器会话；选择「在本机记住」后保存在扩展本地存储，后者不是加密保险箱。连接测试会调用 API，可能产生少量费用。
- **Ollama 本地模型**：先启动 Ollama 并下载模型。默认地址为 `http://127.0.0.1:11434`，支持 `localhost` 与自定义本机端口。刷新模型列表或填写模型名，再保存。连接测试使用本机模型，会占用本机资源。

修改某种方式的页面预算，从下一次请求生效，保留已用量和在途预留量，不取消在途请求；该方式此前手动追加的额度会清除。原样保存不改变额度。已经因预算暂停的页面需手动点继续；「增加预算并继续」每次追加该方式配置的一份额度，仅对本页有效。DeepSeek 账户余额不足会单独提示，增加页面预算不能解决。

缓存只保存文本及身份信息，不保存整页 HTML 或 DOM 引用。组缓存最多 1,000 项 / 2,500,000 字符，单块缓存最多 4,000 项 / 2,000,000 字符，划词缓存最多 50 项 / 200,000 字符；包含缓存身份的字符数，按最近使用淘汰。模型会读取同组邻近内容，因此新增导航项或改变标题可能使对应组的语境变化，需要重新翻译。

英译中建议从 `qwen3.5:4b` 或 `gemma3:4b` 起步，例如先运行 `ollama pull qwen3.5:4b`。更小的模型虽然可能通过连接测试，仍可能漏译或误译术语；更大的模型也不保证每句话都更准确。请在实际网页上试译后选择。

本地模型会收到明确的译文 JSON 格式要求，点号式 API 名称会先变成占位符，翻译后还原。若一个批次的输出不合格，扩展会自动拆成更小批次重试。若模型反复破坏嵌套链接等行内标记，单条译文会改用纯文字显示；原网页的链接和格式仍保留。明显未译为中文的长段落会被视为失败。失败的本地请求不消耗页面预算。DeepSeek 请求若已开始但失败，因费用状态可能未知，页面预算仍会保守记入该次请求的估算用量。

打开或刷新普通 `http://`、`https://` 网页，右侧中间应出现「译」。悬停可查看进度、暂停/继续、重试和设置；点击浏览器工具栏图标也能切换翻译。设置页与 `chrome://` 等浏览器内部页面无法注入悬浮球。若普通网页看不到，先退出全屏，再检查该扩展的「网站访问权限」并刷新网页。

如果 Ollama 测试显示 **HTTP 403**：在扩展管理页打开 myTranslater 的「详细信息」复制扩展 ID；彻底退出 Ollama，在 Windows「编辑账户的环境变量」中新建或追加 `OLLAMA_ORIGINS=chrome-extension://<扩展 ID>`，再启动 Ollama。若已有 `OLLAMA_ORIGINS`，用英文逗号追加这一项。只放行本扩展即可，不必使用通配符。详见 [Ollama 官方来源设置说明](https://docs.ollama.com/faq#how-can-i-allow-additional-web-origins-to-access-ollama)。插件只接受本机回环地址，不接受网页指定任意服务地址。
